= Sayland

Simple Wayland client and server library in Haskell. Allows you to act on events and send requests. +
Currently it's a work in progress with many events and requests missing but it's enough to write a simple bar or compositor.

== The dejafu branch

This branch is a version of Sayland for finding race conditions with https://hackage.haskell.org/package/dejafu[dejafu].
It is for testing only: it cannot talk to a real compositor or client, and `main` does not depend on dejafu.

* The library runs in dejafu's `ConcIO` instead of `IO`, so dejafu's scheduler sees every thread, lock and transaction
and can try the ways they interleave.
link:lib-wire/Sayland/Internal/Conc.hs[`Sayland.Internal.Conc`] gives its `IORef`, `MVar`, `TVar` and `STM` the names main
uses, and the custom Prelude exports them.
* Sockets, file descriptors and shared memory are simulated by link:lib-wire/Sayland/Kernel.hs[`Sayland.Kernel`], with
transactions, so dejafu can also interleave messages arriving with the threads that handle them.
The kernel notices memory that is used after it was unmapped, which a real one would not.
* `cabal test` runs main's tests, each once on the simulated kernel, and the race tests in
link:test/Races.hs[`test/Races.hs`], which dejafu explores.

=== Race tests

A race test is a scenario: a setup, run once, then a concurrent part whose interleavings dejafu explores, up to two
preemptions and with relaxed memory for `IORef`s. A test fails if any interleaving breaks what it checks, so *a failing
race test is a race it found*. Each one's comment says what the race is.

The failure shows the interleaving: how it ended, the order the threads ran in, and the Wayland messages each thread
sent and received in it, like `WAYLAND_DEBUG=1` would. Set `RACE_TRACE=1` to also see every step of every thread.
Run one test with `cabal run sayland-tests -- -p '<name>'`.

=== Keeping up with main

Merge main into this branch, then port what changed:

* `IO` is `ConcIO`, `liftIO` is `liftConc` and `MonadIO` is `MonadConcIO`. The concurrency primitives come from the
Prelude, not from `base` or `stm`.
* System calls (sockets, `mmap`, `setFdSize`, `closeFd`, ...) go through `Sayland.Kernel`. Handlers get the kernel with
`getKernel`.
* `error` in the monad becomes `throwIO`: dejafu can only trace exceptions thrown in its monad.
* New tests run in `ConcIO`: a test like main's with `runOnce`, a race test with `raceTest`.

== Usage

Don't. +
Currently the API is not even close to stable and the supported protocols are not fully implemented yet.
The documentation is also poor right now and there aren't enough tests.

== Documentation

View online at https://saygo-png.github.io/sayland/ +
or build locally using `cabal run genHaddocks` and open `docs-html/index.html`.

== Projects using the library

- https://github.com/saygo-png/Saywallpaper[saywallpaper] -- wallpaper daemon using the `wlr-layer-shell-unstable-v1` protocol.
- https://github.com/saygo-png/saybar[saybar] -- bar using the `wlr-layer-shell-unstable-v1` protocol.

The demos are on main: they need a real compositor, so this branch does not have them.

== Building

Build with Nix flakes: `nix build`.

Build using Cabal: `cabal build`.

== Contributing

The project provides a Nix dev shell with Haskell tooling. +
You can use it with `nix develop`.

You can format the entire project using `treefmt` or `nix fmt`. +
There also is a githook that formats using `treefmt` on each commit.

Run tests using `cabal test`.
To run a single test use `cabal run sayland-tests -- -p <test-name>`.
To see other test options use `cabal run sayland-tests -- --help`

To generate docs use `cabal run genHaddocks -- [output directory]` (default `docs-html`). +
This program builds both libraries into one site with `cabal haddock-project`, fixes links between them,
and removes bogus warnings related to https://github.com/haskell/haddock/issues/1071.

To inspect generated protocol code run `cabal run unrollTH`.
