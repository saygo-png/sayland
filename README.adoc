= Sayland

Simple Wayland client and server library in Haskell. Allows you to act on events and send requests. +
Currently it's a work in progress with many events and requests missing but it's enough to write a simple bar or compositor.

== Usage

Don't. +
Currently the API is not even close to stable and the supported protocols are not fully implemented yet.
The documentation is also poor right now and there aren't enough tests.

== Documentation

View online at https://saygo-png.github.io/sayland/ +
or build locally using `cabal run genHaddocks` and open `docs-html/index.html`.

== Projects using the library

- https://github.com/saygo-png/Saywallpaper[saywallpaper] -- wallpaper daemon using the `wlr-layer-shell-unstable-v1` protocol.
- https://github.com/saygo-png/saybar[saybar] -- bar using the `wlr-layer-shell-unstable-v1` protocol.

You can also check out the demos, which run with `cabal run <name>`:

== Building

Build with Nix flakes: `nix build`.

Build using Cabal: `cabal build`.

== Contributing

The project provides a Nix dev shell with Haskell tooling. +
You can use it with `nix develop`.

You can format the entire project using `treefmt` or `nix fmt`. +
There also is a githook that formats using `treefmt` on each commit.

Run tests using `cabal test`.
To run a single test use `cabal run sayland-tests -- -p <test-name>`.
To see other test options use `cabal run sayland-tests -- --help`

To generate docs use `cabal run genHaddocks -- [output directory]` (default `docs-html`). +
This program builds both libraries into one site with `cabal haddock-project`, fixes links between them,
and removes bogus warnings related to https://github.com/haskell/haddock/issues/1071.

To inspect generated protocol code run `cabal run unrollTH`.
